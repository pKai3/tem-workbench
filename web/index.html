Overlay key and interpretation

Solid rings: matched peaks. Short-dashed rings with a small centre dot: additional weak maximum. Dotted rings: no assigned strong or weak maximum. Faint rings: position could not be checked reliably. Dashed rings: rejected fit. Diamonds: geometry-only grids (purple: primary; teal: secondary), with no phase assigned. The separate geometry check uses freely fitted reciprocal grids and different acceptance rules. Showing a fit does not accept it or change its phase label.

    Analysis settings

    HCP a = 0.295 nm, c = 0.468 nm. Fixed modes use the same selected scale in every region. Automatic modes fit each candidate independently in every region within reciprocal scale multipliers 0.85–1.15. Model a = reference a / fitted a* scale, and model c = reference c / fitted c* scale. Automatic fits use a soft scale penalty: strength × mean[((multiplier − 1) / 0.05)²]. At the default strength 0.10, a uniform 5% adjustment costs 0.10 score and 10% costs 0.40. HCP a* and c* costs are averaged, so a uniform change is not charged twice. Zero disables the penalty; fixed comparison modes are not penalized. This is an adjustable preference for smaller changes, not a calibrated strain limit. It acts before choosing the best zone axis; rank score must still exceed 0.20. The two-scale HCP mode retains extra flexibility. If two accepted structures explain exactly the same profiles, a positional-score leader that needs more fitted scale parameters or more unsupported predictions remains ambiguous. Scale comparison is available for all images and remembered per image in this browser. It resizes model predictions; measured FFT axes and spacings keep the stored DM4 calibration. A better fit after resizing does not establish lattice strain or confirm a phase. Peak coverage is the matched share of the total weight of original detected peak profiles. Weights depend on height above the radial background and are capped at 1–6. It is not an intensity fraction, phase fraction or probability. Peaks S+W / all separates original strong profiles from additional weak maxima. Prediction-site checks use a search radius of one Hann peak width (at least 0.10 nm⁻¹), local background, and rotated control positions. The evidence weight adds modest weak-support credit and subtracts a cost for unsupported predictions. Zero disables both adjustments. Weak maxima do not count toward the four-profile screen or separate-pattern criteria. Missing reflections can be suppressed by image formation; these are exploratory ranking weights, not probabilities.
