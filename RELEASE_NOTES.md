# TEM Workbench 1.0.41

- Browse HCP, BCC, FCC, omega and orthorhombic crystals as bubbles, ball-and-stick models or wireframes. Open fitted candidates directly with **View 3D**, using their fitted detector orientation and configured phase colours.
- Preview kinematic diffraction alongside the atomic model, with zone selection, off-axis tilt, free rotation, smooth snapping and a standard-zone tour. Candidate exploration smoothly returns to the fitted orientation unless Free rotation is selected.
- Compare the original image, measured FFT, atomic model and simulated diffraction in four square panes. Moving the image selection updates the previews; FFT and simulated diffraction share their display scale and fitting radius.
- Add shared map-export settings with live PNG previews, Standard/Paper styles, transparent/white/dark backgrounds, configurable legends and scale bars, and optional sample names. Main maps, PCA/NMF inspectors and batch exports use the same settings.
- Improve Figures with short SEM scale-bar detection, shared colour suggestions, label-shade application by row or column, larger layouts and exports without the former panel/pixel caps. Shared notifications report saving and export progress.
- Show a loading indicator while figure previews render and decode, with visible errors and protection against outdated responses.

Diffraction intensities are an approximate kinematic preview, not a quantitative match to the measured FFT. Source microscopy files and crystal-fitting algorithms are unchanged.

Use **Check for updates → Install update and restart**.
