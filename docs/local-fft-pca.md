# Local FFT PCA / NMF (experimental)

Available on `feature/local-fft-pca`; not included in main v1.0.32. Open a calibrated real-space image, then choose **Local FFT PCA / NMF** beside the automatic-grid window-size check. Restart using this branch to enable its API. The regular grid and crystal matcher are unchanged.

## Using it

1. Choose window width and centre spacing. Defaults are 10% and 5% of the shorter image side. Choose square or hexagonal sampling centres and 1, 3 or 9 shifted placement passes. Sample image rim adds full-size border-anchored windows for each pass (default on). Full square physical windows sample the image; the current region/polygon does not restrict the run. Pixel rounding is reported in the result.
2. Choose **PCA** (default, four signed components) or **NMF** (nonnegative components). Begin with zero rotation/spacing smoothing. The run snapshots current material/phase/scale settings, FFT taper, mean removal and inner/outer limits. Detector thresholds and crystal scores do not enter decomposition.

   For PCA, **Combination fitting** offers Together (default), All combinations or Off. All computed PCs participate initially; each Signals card has a top-right **Use in fitting** checkbox. It selects both positive/negative features and combination membership. **Refit selected** updates crystal fits and mapping without recomputing PCA. Combinations use each sampled window's signed scores, so all subsets can be substantially slower. Run PCA automatically continues through fitting and original-window checks.
3. Results open in **Signals**, with compact cards packed from the left. All computed signals stay visible; clicking a header enlarges that card in place. Inspect component maps and spectra. Header bars fill horizontally on a fixed 0–100% scale: PCA shows explained variance, and NMF shows **signal share** after spectral normalization, not explained variance or phase fractions. Blue/red PCA maps show opposite deviations from the mean. NMF spectrum clicks or each card’s **Fits** button open crystal inspection. Click a map location or use arrow keys to inspect its spectrum and reconstruction.
4. Select components to inspect their combined activity and reconstruction. NMF adds nonnegative contributions. PCA adds the mean to the reconstruction; PCA group activity is the square root of the sum of squared scores and discards sign.
5. For gradual lattice drift, compare a new run with modest rotation or spacing smoothing. These are Gaussian standard deviations, not permitted fitting ranges. They broaden peaks before decomposition; they neither register orientations nor force one crystal into one component. Compare against the preserved original sampled spectra.
6. **Run NMF** automatically performs decomposition, fits every nonempty component combination against the captured phase/template library, then builds phase-support maps. Completed stages appear while the next runs. **Fit all combinations** and **Build phase maps** remain available for separate reruns. Adjust **Factor peak cutoff** if needed; this is relative signal height, separate from ordinary FFT detection controls. A progress bar counts completed combinations; Cancel preserves completed groups and the decomposition. Click a result’s component numbers to inspect its spectrum and checks against original windows.
7. **Export data** writes an NPZ containing the numeric arrays and a JSON containing the source identity, calibration, settings, sampling positions, representation and method version. Exports go to the source's configured output folder. Completed fits, phase-support maps and their completion/cancellation status are included. Every retained component is exported; the current visual checkbox selection is not a separate scientific result.

Setup controls are separate from the results. Use the **Signals**, **Crystal fits** and **Mapping** arrow tabs to switch stages. Mapping supports both PCA hypotheses and NMF phase support. Both methods have crystal-fit inspection. Signal display controls change presentation, not the decomposition or fits. Group activity and unexplained variation remain compact views; the separate single-signal layout and variance/share chart are removed.

Close the workspace without cancelling to let a run finish while the browser page remains open. Cancel or a failed stage stops the automatic sequence and retains completed results. Only the most recent decomposition result is retained in memory. Restarting the app loses it unless exported. There is no in-app NPZ reimport yet. Grid, batch and size-check jobs cannot run concurrently with decomposition or factor fitting; ordinary region inspection remains available.

**Run PCA** now continues through separate positive/negative feature fitting and original-window checks. Each card has **Fit +** and **Fit −** buttons; **Fit both sides** and **Check original windows** rerun those stages. Cancel stops the pipeline and retains completed results.

The PCA/NMF pipeline currently uses one background analysis worker at a time. Sampling, decomposition, combination fitting and support mapping are sequential. The standard server limits numerical-library threads to one, and local FFT sampling explicitly uses one FFT worker; the automatic-grid worker selector does not apply.

## Representation and equations

For each sampled window, mean subtraction (if enabled) precedes the selected Hann/Tukey/rectangular aperture. The spectrum is

    L(q) = log(1 + |FFT(windowed image)|² / pixel_count)

It is antialiased and interpolated onto 96 logarithmically spaced radial bins and 180 angular bins spanning 0–180°. Opposite samples are averaged, appropriate for the power spectrum of a real-valued image. Axes use g = 1/d, qx to the right and qy upwards. The inner and outer radii are the captured fitting limits; the outer radius must lie below both Nyquist limits. No peaks are detected or selected during decomposition.

Antialias smoothing is applied in native reciprocal coordinates with sigma equal to half the largest outer-edge target bin width. This makes downsampling less sensitive to pixel placement. The “Original spectrum” view is this sampled, antialiased log-power representation, not the original native FFT array.

Optional broadening operates in angle and log radius. Angular boundaries wrap at 180°; radial boundaries use nearest extension. A spacing sigma of p% uses log(1 + p/100). Reciprocal-area metric weights are proportional to radius (the square root of the log-polar area Jacobian), normalized to unit RMS. With unit-norm normalization, each weighted window is divided by its own norm before centering across windows. None retains brightness variation.

    X = processed window spectra
    mean = mean(X, axis=windows)
    X_centered ≈ scores @ components
    reconstructed = mean + selected_scores @ selected_components

PCA uses exact SVD for at most 64 samples/features on the shorter matrix axis; larger jobs use a seeded randomized range (seed 0, three power iterations, twelve oversampling directions). Each component's largest absolute loading is given positive sign for repeatability. Explained variance is captured score energy divided by total centered energy, not renormalized to the retained components. Residual maps show the unexplained norm after all retained components.

Display reconstruction reverses area weighting and row normalization. Negative reconstructed bins are retained numerically but displayed black; their fraction is reported. Original, broadened and reconstructed spectra share one intensity range per inspected window. Component spectra have a separate symmetric signed scale. The mean normalized input spectrum is not directly intensity-comparable with the unnormalized original mean.

### PCA display comparison — implemented 12 November 2026

**PCA contrast → Per signal** retains independent contrast for inspecting each component. **Shared across signals** uses one symmetric, zero-centred score range across **all computed PCs**, including those outside the current selection or page. Spectra show each loading multiplied by its component's RMS score, with a second shared symmetric, zero-centred range. Map scores and weighted spectra have different units and do not share a numerical range. This exposes relative component amplitude without discarding weak components or declaring them noise. With normalized input, it is not a comparison of physical diffraction intensity.

Map contrast is display-only: **Enhance variation** maps an unsigned map's 2nd–98th percentiles to blue–cyan–yellow and clips extremes. **Full range from zero** preserves zero as the lower colour bound. Read the numerical range in the legend: a vivid map can represent small variation, not phase separation or confidence. Signed PCA maps retain their diverging palette and zero reference. These controls do not change the fitted data.

## NMF and exhaustive crystal fitting

NMF uses the same nonnegative processed spectra without across-window mean centering:

    X ≈ W H, with W ≥ 0 and H ≥ 0
    H ← H * (Wᵀ X) / (Wᵀ W H)
    W ← W * (X Hᵀ) / (W H Hᵀ)

Products/divisions in the updates are elementwise, with a positive denominator floor. A fixed random seed makes runs reproducible. The solver checks relative squared-error improvement every ten iterations, stopping after at least fifty iterations when improvement falls below 1e-5, or at 300 iterations. This finds a local solution, not a guaranteed global optimum. Residual/error measures use the processed, weighted matrix.

Each row of H is normalized to unit L1 sum and the corresponding W column multiplied by that sum, preserving W H. **Signal share** is `sum(W[:, k]) / sum(W)`, after this normalization. The algorithm does not require equal shares. Group activity adds selected columns of W. No mean term is added to NMF reconstruction. With normalization enabled these are contributions to normalized log-power spectra, not measured phase abundances, physical intensity fractions or explained variance.

Two saved five-factor Ti 0274 runs (12 November 2026, with 2°/2% broadening and without broadening) gave shares of 19.63–20.27% and 19.48–20.20%. Their factor spectra were highly similar: median pairwise cosine similarity 0.943 and 0.923. An azimuthal-median radial-baseline diagnostic accounted for 96.3–99.7% of factor L1 mass across the two runs. Both reached 300 iterations without convergence. This supports a shared diffuse-background explanation for the nearly equal shares in these runs; it does not establish five equally abundant phases. The baseline metric is `180 × sum_r median_angle(H) / sum(H)`, not a physical background measurement. These are five-factor diagnostics, not a reproduction of the later eight-factor screenshot.

Exhaustive fitting visits all `2^K − 1` nonempty subsets: four factors give 15 groups, six give 63, and sixteen give 65,535. It never silently falls back to pairs or a restricted search. Progress counts fully completed groups and names the current template. Cancellation is checked between template fits; it cannot interrupt an individual numerical fit. The table loads 100 rows at a time, with all completed groups available through subsequent pages and exports.

For each group, a window is considered co-occurring when every included factor reaches at least 20% of its own maximum coefficient. Mean coefficients across those windows weight the combined spectrum. If no window qualifies, global mean coefficients are used and the group is explicitly marked hypothetical. This threshold reports spatial support; it does not prune combinations. Rescaling any factor and inversely rescaling its coefficients leaves the combined spectrum unchanged.

The detector subtracts each radial bin's median over angles, takes local maxima above the user-controlled fraction of the strongest residual, and applies the captured physical minimum-separation and profile-count controls. The default **Peak cutoff** is **0.35** (increased from 0.20 on 12 November); explicit saved cutoffs remain in use for inspection and original-window checks. Profiles have equal weight. Angular sampling identifies opposite reflections as one profile. The fitting width uses the same native FFT taper response as ordinary FFT analysis, with a minimum of 0.1 nm⁻¹: Hann 1.44 bins, rectangular 0.886 bins, or the selected Tukey response. Optional decomposition broadening does not enlarge this width. This is still a relative-height detector, not a calibrated noise/significance test; its thresholds are separate from ordinary FFT photometry.

The existing single-crystal matcher searches each group's peaks using the captured phase library, reference dimensions, scale mode, penalties and omega tolerance. It reports the highest-ranked candidate per phase, ranked by positional agreement minus chance allowance and scale costs. Ordinary weak/missing-peak photometry and double-diffraction adjustments are not applied to factor intensities. These exploratory ranks must not be compared directly with main-analysis ranks. This does not perform a joint beta-plus-omega model search.

Candidate inspection retains up to five geometrically distinct fits per phase. Within the same phase and zone, near duplicates keep the **higher-ranked fit unchanged**, without pooling their matched peaks. Predicted positions are paired one-to-one, treating opposite reflections as equivalent, within **one positional matching width** (the smaller width if they differ). At least four pairs with nonparallel spread are required, and every interior prediction must pair. Unpaired reflections are allowed only within that distance of a shared fitting-band boundary, where a small metric change can move a reflection into or out of view. Different phases, zone alternatives and linked component identities stay separate. Resolved rotation or cell-metric differences also remain available even when their rounded labels or assigned peak IDs agree. This is a deduplication heuristic, not a statistical resolution estimate or evidence of multiple physical patterns. Legacy records without geometry/width metadata retain the previous >80% matched-profile overlap fallback.

**Pass** permits a partial alternative explanation: at least four assigned profiles, nonparallel directional spread, more than 30% **observed-profile** coverage, and positional and penalized scores above 0.20. It does not require all predicted reflections to be observed. Assignments may be displaced (up to four matching widths), with progressively less positional credit; there is no missing-prediction cost in this search. Thus HCP and omega can both pass without either explaining the complete group. The inspector now distinguishes assigned predictions with solid outlines from unassigned predictions with faint dotted outlines; assigned predictions from a below-screen candidate remain dashed. Observed-profile and prediction coverage are displayed separately. Candidate rows show residuals, Position, Scale cost, Cell (a/b/c in nm) and Cell Δ (including c/a where fitted) directly, using the normal results-table formatting. The summary table uses the same columns. Below-screen reasons and matching limits remain in tooltips on Screen and Matched profiles. Original-window scale cost includes source and local-refinement costs, and cell changes reflect the locally refined scale. Narrow tables wrap their secondary measurements onto a labelled row instead of hiding them in disclosures. This display correction does not change ranks, assignments or acceptance thresholds.

For the best candidate, up to three strongly co-occurring original sampled windows are checked at the fitted prediction positions without refitting. These are within-image consistency checks, not independent validation. Combined spectra, source-window checks and alternative phase ranks are available using the group’s **Fits** button. Clicking its number opens the group activity map and combined spectrum. The group table includes fitted rotation. The NPZ/JSON export preserves all completed groups, coefficients, co-occurrence counts, fitting settings and checks; cancellation leaves a partial export available.

## NMF group support and phase maps

Passing group hypotheses are checked against every eligible original, unbroadened sampled window with bounded local refinement (±3° rotation and ±3% uniform reciprocal scale; fixed-scale mode allows rotation only). Cell proportions and phase/zone identity remain fixed. Eligibility requires each included factor to reach 20% of its own maximum activity. Activity alone is not evidence of a phase. The highest-ranking passing model per phase is retained; overlapping groups are never summed.

Local support is the sum of positional match qualities divided by predicted-profile count, minus a chance-match allowance and scale costs. Extra observed peaks increase the chance allowance rather than diluting genuine support. Original group scale costs are retained; local scale drift adds a cost. Passing requires at least four matches within one matching width, nonparallel directions, >30% prediction coverage and support >0.20. Farther assignments still contribute decreasing positional credit up to four widths, but do not count toward that four-profile minimum or close-match coverage. The inspector's help and expanded candidate details report the numerical cutoff. This is a different metric from group-search rank. Multiple-phase labels require each included phase to explain at least three distinct nonparallel profiles and more than 15% of the detected profiles. Close competing explanations of shared peaks are labelled ambiguous. Otherwise the window remains unresolved. Phase-specific views include passing models even when the all-phase classification is unresolved or ambiguous.

These maps are same-image consistency checks, not phase fractions or independent validation. Drift beyond the refinement bounds can still be missed. Poor peak extraction and unconverged NMF can also leave many windows unresolved; the convergence status stays visible. Models, per-window evidence, classification thresholds and limitations are exported.

## Signed PCA feature fitting — implemented 12 November 2026

Each component supplies two separate hypothesis sources after reversing reciprocal-area weighting:

    positive = max(component / area_weights, 0)
    negative = max(-component / area_weights, 0)

No offset or mean is added to make a component nonnegative. Both sides use the same radial-baseline peak extraction and captured crystal library/scale settings as component fitting. The feature cutoff is relative to the strongest residual on that side, not an absolute intensity threshold. Up to five distinct candidates per phase per side are retained, including multiple orientations of the same phase. The partial observed-profile screen applies to these feature hypotheses; it is not proof of a pattern in the original image.

Before original-window checks, the same geometric deduplication groups repeated hypotheses across components, signs and combination sources. Each group keeps the highest-ranked source fit unchanged and records every source component/side, group/candidate index, source rank, screen and rotation. Combination sources also record their actual window and signed coefficients. The per-source inspectors remain available; deduplication itself does not combine loadings or scores. A candidate must agree with the retained representative, rather than an intermediate neighbour, so a chain of small rotations cannot merge distant orientations. The window selector lists all source labels once, and source buttons reopen their individual fits.

Every distinct hypothesis, including below-screen feature fits, is then checked once against **every original, unbroadened sampled window**, including opposite-sign and zero-score windows. Support counts are recomputed for the representative, never added across sources. The mean remains available in the workspace and reconstruction. Neither score sign nor activity gates the checks. Local support reuses prediction-normalized positional agreement minus chance and scale costs, four close profiles, nonparallel spread, more than 30% prediction coverage and support above 0.20. Refinement is bounded to ±3° rotation and ±3% uniform reciprocal scale, with rotation only in fixed mode. Phase, zone and cell proportions remain fixed.

The **Mapping** hypothesis list retains phase, zone and orientation identities; each name’s tooltip lists its component/sign sources, with source buttons available when isolating a hypothesis. Its count is the number of original windows supporting that hypothesis; overlapping hypotheses are not summed. Selecting a window shows the representative lobe source's signed PC score, where applicable, and support metrics. **Inspect** opens the original sampled spectrum with locally adjusted predictions and close assignments. Source rank and original-window support are labelled separately because their normalization differs. The display modes below choose a global candidate pool and assess its local support.

PCA signs are arbitrary: flipping a loading and its score column swaps positive/negative source labels but leaves physical candidates and original-window support unchanged. A component can contrast two orientations of one phase; the same pattern can be present in the mean and pass in both positive-score and negative-score windows. Noise and gradual drift can also generate signed features. Numerical NPZ/JSON exports include the original signed arrays, per-side fits, per-hypothesis window checks, thresholds and provenance; decomposition/reconstruction arrays are unchanged.

Synthetic controls cover sign-flip invariance, two orientations of the same phase (including two on one side), a zero-score mean window containing both patterns, weak lobe amplitude, flat/no-signal lobes, bounded drift, cancellation and export round trips. Existing local-support noise controls remain in force. Independent known-phase validation and drift beyond the refinement bounds remain limitations.

## Score-weighted PCA combinations — implemented 12 November 2026

For selected component subset S at sampled window i, proposal spectra are the partial reconstruction:

    (mean + scores[i, S] @ components[S]) / area_weights * normalizations[i]

Both the mean and signed coefficients matter. Reversing any loading and its corresponding score column leaves this reconstruction unchanged. The array is not shifted or sign-flipped to make it positive; the detector uses the existing positive excess above each radius's median. Negative reconstructed pixels are reported in inspector help. The hypothesis is then checked against the original **unbroadened** sampled spectrum, not accepted from the reconstruction alone.

**Selected PCs together** searches one subset of two or more selected PCs at every sampled window. **All selected subsets** searches all groups of two or more: three selected PCs give 1+2, 1+3, 2+3 and 1+2+3. Individual positive/negative features remain available in either scope. There is no global averaging of signed scores or activity/sign eligibility gate. All requested subset/window pairs are visited. A bounded cache reuses a crystal search only for identical ordered detected-peak coordinates; search weights are uniformly one. Relative detection heights are not rank inputs. Up to five geometrically distinct candidates per phase per subset are retained, each with its exact representative window and coefficients. This is an explicit proposal-retention limit, not exhaustive retention of every local fit.

Progress counts individual sides plus subset/window fits. With K selected PCs and W windows, all-subset work is `2 × computed PCs + (2^K − K − 1) × W`; this can grow rapidly. Execution remains one worker. Cancellation retains completed work and partial per-subset progress for export. Source links open the exact score-weighted spectrum, coefficients and fit; ordinary window links always open the original data. Numerical PCA arrays are unchanged.

## Selectable hypothesis maps

The hypothesis list beside the map shows structure, zone axis, representative rotation and Passing/Cumulative passing/New/Better percentages. **New + improved windows** (default) greedily chooses each next hypothesis by the number of windows newly supported or improved relative to earlier choices. Ties prefer new coverage, then total score gain, then passing count/mean support/stable ID. **Improved windows first** prioritizes improvements to already-supported windows, then new support, then the same remaining tie-breakers; its first choice is seeded by passing coverage. **Passing windows** retains the original total-passing-count order, with mean passing support and stable ID as tie-breakers. **Select top** checks the first N in the chosen order; checkboxes allow a custom pool. Sorting preserves manually checked identities but reapplies the count for a Top-N preset. **Best local match** (default) colours each window centre by the highest-support passing member of this fixed pool, not the globally highest candidate everywhere. If none passes there, the centre remains unresolved; it does not substitute a candidate outside the pool.

**All locally supported** displays every passing pool member as coloured sectors of the centre circle. Clicking a hypothesis name selects only that hypothesis and retains individual source links; this replaces the separate Single hypothesis mode/dropdown. **Colour by Phase / Hypothesis** distinguishes either structures or individual orientations. These are display controls; they do not rerun or change fitting. Counts for the pool are a union of supported windows, not a sum of overlapping hypothesis counts.

The selected-window table reports every pool candidate, highlights the local winner and opens its original-window overlay. Separate-pattern support requires each chosen pattern to own at least three distinct profiles, more than 15% of observed profiles, and nonparallel spread above 0.5 in absolute sine. Close alternative fits within 0.08 support and sharing over 60% of the primary profile set are competing explanations when no separate-pattern set is established; a white map corner marks that ambiguity. Its legend entry explains the marker on hover, keyboard focus or tap. Same-phase orientations remain separate candidates. Displaying several passing fits does not by itself prove coexistence. This is an exploratory **phase-support map**, not a phase-fraction measurement or independent validation.

**Solution symbols** identify the highest-support passing solution at each visible window centre, including when all locally supported colours are displayed. Different retained orientations of the same phase/zone have different symbols. Only solutions that win somewhere in the current pool appear in the symbol legend; its counts are locally winning visible windows. Symbols stay stable while changing the pool, display and colour setting within these results.

Select top contains counts only. The list’s **Cumulative passing** column gives unique supported-window coverage through that row; **New** and **Better** describe adding that row after every preceding row in the current ordering, independent of manual ticks. Better counts already-supported windows whose best passing local support strictly increases from N−1 to N; new coverage is counted separately. The map summary instead reports the actual checked pool’s unique coverage; an automatic Top-N pool also reports the last addition’s new/better split. Ties and below-screen fits contribute no improvement. All percentages use the total number of checked windows, including unresolved windows, as the denominator. They describe changes in the displayed explanation, not a probability or a statistical significance test.

## Overlapping stability mapping — implemented 12 November 2026

**Mapping** uses original-window fit support. **Mode** selects Individual windows, Match score, Match frequency, Best match, Placement sensitivity or Sampling density; **Display** selects a continuous or hex map for aggregated modes. Hexagonal display is independent of square/hexagonal sampling. New runs default to hexagonal centres, one pass and rim sampling. Existing retained rectangular runs remain readable; rerun decomposition to add new edge samples or shifted placements.

Individual windows uses the main map's circular centre markers. **Centre markers** offers Circles, Circles + zone icon or Zone icon for both PCA and NMF. **Show rim points** hides or shows the extra boundary samples in this view and its PNG; hidden centres are also omitted from symbol counts and selection. Rim points remain visible while mapping runs. All samples still contribute to the analysis and aggregated maps. Marker and rim choices survive viewer reloads.

**Export map PNG** saves the current map and legend to the configured output folder, using the displayed colours, opacity and rim preference. It includes concise source/sampling information, without the selected-window outline or progress message. Export becomes available when mapping and any pending aggregation finish; completed partial results retained after cancellation can also be exported.

The sampler and numerical aggregation are shared with the ordinary overlapping grid. Each location combines checked windows covering it with Gaussian centre weights. Each placement pass is normalized separately, then available passes are averaged equally. Match frequency counts passing support; Match score uses the best passing local score per phase/hypothesis, with failed or missing fits contributing zero. Repeated sources or two passing hypotheses of the same phase never add duplicate phase support. PCA uses only the selected hypothesis pool; NMF keeps its existing activity eligibility and per-phase local checks. Unchecked windows do not enter the denominator. Best match uses the highest average available score and fades with passing frequency. Placement sensitivity is the range of per-pass passing frequencies, available with two or more completed passes.

Colour by Hypothesis keeps retained PCA orientations separate. The main phase-colour blending rules are reused. Fixed opacity is the default; Normalise opacity scales all displayed phases by one common maximum without changing values or colour ratios. Continuous display interpolates a sampled map raster; hex tiles directly evaluate the same aggregation at their centres. Neither performs another crystal search. Hover shows contributing-window counts, passing frequency and score. Clicking opens an actual contributing original window, never an averaged or synthetic FFT.

Full-size rim windows touch every image boundary, including corners, without padding the source or shrinking the FFT. Each placement pass includes its own rim. Samples, pass IDs, rim flags and positions are exported, along with original-window checks, so the maps can be reproduced. The spectral-matrix memory limit still applies to all samples including rims and passes; increase spacing or reduce passes if exceeded. Signal-card maps use the nearest actual sampled window without stacking opacity in overlapping cells.

These views measure same-image consistency under overlapping placements. Their support percentages are not area fractions, and neighbouring windows are correlated. Neither PCA nor NMF provides independent phase validation.

## Window and mean-spectrum views

Completed source-fit tables and inspectors are available while original-window checks continue. The progress readout identifies this stage. Source inspection and spectrum previews do not restart the analysis; settings/refitting remain locked, and completed-window overlays become available after the support stage. Support completion preserves an open source inspector.

Selected-window Original spectrum / Selected reconstruction previews are up to 450 px wide (previously 180 px). They appear only in Signals, where the component maps can change the selected window. Mapping retains original-window scores and fit inspectors, without the component-reconstruction preview. **Smoothed input** appears only when the completed result used nonzero angular or spacing smoothing. All displayed selected-window spectra retain the same intensity range; no extra smoothing or fitting allowance is introduced.

Original-window fit headings show the window and crystal identity/rotation. A source-history tooltip explains that combined-PC reconstructions and signed component features may independently propose the same geometry, which is retained as one hypothesis. The original-window check tests that retained hypothesis on the selected original spectrum; slash-separated sources were provenance, not an additional sum of spectra.

Mean diagnostics are collapsed under Signals only. **Average original spectrum** averages the sampled log-power spectra before optional smoothing and normalization. **PCA baseline** averages the decomposition inputs after the selected smoothing and per-window normalization. Reciprocal-area weighting is reversed for display, but each window’s brightness normalization is not undone in this global mean. It is the mean removed before PCA and restored during reconstruction. It may differ from the original average even with zero smoothing; the two mean images use independent display scales. NMF instead shows a mean reconstruction and does not subtract a PCA baseline.

Smoothing before decomposition can alter component separation; downstream bounded local rotation/scale refinement instead checks an already-retained crystal hypothesis. These are distinct operations. Zero optional smoothing remains the default; its display is suppressed when unused.

## Interpretation and limits

A component describes correlated variation. It can represent a phase, orientation, thickness, background, contrast or distortion—or part of several effects. One crystal may require multiple components; one component may mix crystals. There is no promise that smooth rotation belongs to a single principal component. Broadening can hide real differences, and group activity is not phase abundance. NMF factors are also exploratory; the crystal fits do not replace ordinary region/grid classifications.

The common spectral grid limits reciprocal detail. Spatial resolution is governed by FFT window width, not just centre spacing; neighbouring windows are correlated. Individual-window displays represent sampling centres; stability displays aggregate overlapping footprints. Neither gives exact phase boundaries. Unsampled edge margins remain visible when Sample image rim is off. Changes in retained variance after smoothing do not establish better physical interpretation.

The first pass limits each float32 spectral matrix to 64 MiB (970 windows at this grid size). Multiple matrices and decomposition buffers coexist, so this is not a total memory limit. Windows are limited to 32–2048 pixels per axis. The fitting band must span at least four native FFT bins. Cancellation is checked between windows and matrix stages, not inside a numerical-library operation.

## Validation and next experiments

Automated controls check synthetic spatial separation, PCA reconstruction, seeded repeatability, calibrated reciprocal sampling, angular wrapping, finite/invalid inputs, exports and cancellation. A synthetic small rotation/spacing change becomes less different after broadening while a widely separated orientation remains distinct. This tests the numerical mechanism; it does not validate phase mapping.

ST 1203 completed a 324-window smoke test with and without 2°/2% broadening. Independent known-phase images, gradual-distortion controls, weak secondary patterns and interface localization still need evaluation. Compare with unchanged independent-window matching, keep tuning and validation images separate, and inspect the residuals before adopting factors into classification.
