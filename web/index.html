    Marker styles

    White markers show detected positions; coloured outlines show predictions. Weak detections have their own style and appear only for displayed fits that use them. Bounce changes size; Bounce + wobble adds sideways motion; Bounce + rotate swings −45° to +45° around fixed centres, largest at 0°. HCP and BCC predictions bounce half a cycle apart. Point and geometry markers use separate timing. Off restores exact positions. Phase colours also update the map, legends and fit labels. Display choices do not change the analysis.

    Individual fit overlays — including rejected candidates

    Overlay key and interpretation

    Coloured prediction outlines: long dashes for an assigned weak maximum, whether the fit passes or fails the screen; otherwise short dashes for below-threshold fits. Passing fits use solid outlines for strong matches and dotted outlines when no maximum is assigned. Faint outlines mark positions that cannot be checked reliably. Separate white weak-detection markers sit at the observed positions; their shape can be changed or hidden. Purple and teal outlines are primary and secondary geometry-only grids, with no phase assigned. Marker shapes are selectable independently. The separate geometry check uses freely fitted reciprocal grids and different acceptance rules. Showing a fit does not accept it or change its phase label.

    Brightness controls affect the display only. FFT processing is set above; scaling moves prediction points.

    Ambiguous vs two candidate structures

    Phase ambiguous: Passing fits of different structures explain the same or largely overlapping peaks. They are competing explanations. Their ranks are close, or the leading fit to exactly the same profiles uses extra scale freedom or has more unsupported predictions.

    Two candidate structures: Passing fits of different structures explain separate sets of peaks. Each pattern has its own evidence, so both may contribute.

    Multiple orientations: Separate peak sets support passing fits of the same structure at different orientations.

    A separate pattern must add at least 3 original strong profiles not matched by the leading fit, account for more than 15% of the total weighted peak evidence, and span nonparallel directions. Additional weak maxima do not count toward this check. Neither fit needs 50% peak coverage.

    Ambiguous does not mean a mixture. Two candidate structures suggests separate contributions, but does not confirm two phases or their proportions. The geometry-only check is a separate check of periodicity without assigning a structure.

    Prediction-site evidence

    S = original strong profiles; W = additional weak local maxima. Weak features only adjust ranking. Unchecked positions are masked, outside the detector, near a band boundary, or overlap another prediction. Both phases use the same rules. Hover a row for the full score calculation.

      Analysis settings

      Reference unit cells are set under Material above. Fixed modes use the same selected scale in every region. Automatic modes fit each candidate independently in every region within reciprocal scale multipliers 0.85–1.15. Model a = reference a / fitted a* scale, and model c = reference c / fitted c* scale. Automatic fits use a soft scale penalty: strength × mean[((multiplier − 1) / 0.05)²]. At the default strength 0.10, a uniform 5% adjustment costs 0.10 score and 10% costs 0.40. HCP a* and c* costs are averaged, so a uniform change is not charged twice. Zero disables the penalty; fixed comparison modes are not penalized. This is an adjustable preference for smaller changes, not a calibrated strain limit. It acts before choosing the best zone axis; rank score must still exceed 0.20. The two-scale HCP mode retains extra flexibility. If two accepted structures explain exactly the same profiles, a positional-score leader that needs more fitted scale parameters or more unsupported predictions remains ambiguous. Scale comparison is available for all images and remembered across images in this browser. It resizes model predictions; measured reciprocal axes use the image calibration. For direct diffraction, the centre and reciprocal calibration can be edited above. A better fit after resizing does not establish lattice strain or confirm a phase. Peak coverage is the matched share of the total weight of original detected peak profiles. FFT weights depend on height above the radial background; direct-spot weights use log(1 + local contrast). Both are capped at 1–6. It is not an intensity fraction, phase fraction or probability. Peaks S+W / all separates original strong profiles from additional weak maxima. Prediction-site checks use a search radius from the window width (FFT) or measured spot width (diffraction), at least 0.10 nm⁻¹, local background, and rotated control positions. The evidence weight adds modest weak-support credit and subtracts a cost for unsupported predictions. Zero disables both adjustments. Weak maxima do not count toward the four-profile screen or separate-pattern criteria. Missing reflections can be suppressed by image formation; these are exploratory ranking weights, not probabilities.
