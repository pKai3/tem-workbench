    Analysis settings

    HCP a = 0.295 nm, c = 0.468 nm. Fixed modes use the same selected scale in every region. Automatic modes fit each candidate independently in every region within reciprocal scale multipliers 0.85–1.15. Model a = reference a / fitted a* scale, and model c = reference c / fitted c* scale. Automatic fits use a soft scale penalty: strength × mean[((multiplier − 1) / 0.05)²]. At the default strength 0.10, a uniform 5% adjustment costs 0.10 score and 10% costs 0.40. HCP a* and c* costs are averaged, so a uniform change is not charged twice. Zero disables the penalty; fixed comparison modes are not penalized. This is an adjustable preference for smaller changes, not a calibrated strain limit. It acts before choosing the best zone axis; rank score must still exceed 0.20. The two-scale HCP mode retains extra flexibility. If two accepted structures explain exactly the same profiles, a positional-score leader that needs more fitted scale parameters or more unsupported predictions remains ambiguous. Scale comparison is available for all images and remembered per image in this browser. It resizes model predictions; measured FFT axes and spacings keep the stored DM4 calibration. A better fit after resizing does not establish lattice strain or confirm a phase. Support is the share of detected Fourier evidence; it is not phase fraction or probability. Matches / predictions reports assigned profiles relative to allowed model positions; it does not assume every allowed reflection must be visible.
