# TEM Workbench 1.0.40

- Preview saved figures and AZtec map/line comparisons before opening them. Hover or focus a name to see its saved layout, labels and annotations; keyboard and touch controls are supported.
- Preserve figure annotations by autosaving edits to the active named figure, including edits made before export or switching figures. Replacing an image with identical contents retains its annotations, crop and manual settings; delayed image reads cannot overwrite a different figure.
- Fit the figure panel editor to the window, with a compact header, one row of annotation settings and a small Greek-character popup. Narrow windows offer Source, Adjustments and Annotations tabs.
- Make KAM legends more compact in both previews and exported PNGs.
- Add an optional NMF iteration limit from 1 to 10,000, retaining 300 as the default. Record requested and completed iterations, correct convergence reporting for a short final interval, and include tools for comparing iteration budgets and stopping rules.

Source microscopy files are unchanged. The default NMF solver, seed, preprocessing and stopping tolerance remain unchanged.

Use **Check for updates → Install update and restart**.
