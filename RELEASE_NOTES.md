# TEM Workbench 1.0.26

- Track unchanged images by content so saved regions, calibrations and preferences survive moves and renames after indexing.
- Add multiple project source folders, project filtering, and optional output folders per source.
- Refresh idle image catalogues automatically and report moved or missing files in bottom-right notices.
- Identify image types in file lists and use filenames when acquisition numbers are unavailable.
- Cache image hashes and microscope metadata for subsequent starts. Initial indexing can take longer, especially for cloud files; progress appears in the log.

Use **Check for updates → Install update and restart**. Keep the image registry and project state together; edited or re-encoded images receive a new identity.
